# Changelog

## [0.1.2] — 2026-10-19

- Markdown/HTML combo presets (Bold+Underline, Bold+Italic, strikethrough / `<mark>` mixes)
- Mark+Bold, Mark+Italic, Mark+Underline (HTML `<u>`) over the full Mark matrix

## [0.1.1] — 2026-10-19

- Quick Pick sorts by recently used, then frequently used (`wrapSelection.sortBy`)

## [0.1.0] — 2026-10-16

Initial local-only release (not published to the marketplace).

- Wrap Selection… via Command Palette, `Alt+M`, and editor context menu
- Wrap with Mark… wizard (type → color → brackets)
- Built-in markdown / HTML wraps
- Fenced code block presets + Custom Code Fence…
- Full `<Mark>` type × color matrix (semantic + Tailwind names + `#F08F87`)
- User presets via `wrapSelection.presets` setting
- Multi-cursor support; no-selection warning
